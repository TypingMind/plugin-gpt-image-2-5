## GPT Image 2.5

Generate or edit an image with OpenAI's GPT Image models. Select [GPT Image 2.6 Flare](https://developers.openai.com/api/docs/models/gpt-image-2.6-flare), GPT Image 2.5 Flare, or GPT Image 2.5 Sunburst in the plugin settings. The default is GPT Image 2.5 Flare.

Make sure you’ve entered your OpenAI API key in settings.

Example usage:

> Generate a picture of a cat

> [Image Attachment] Add a hat to this cat
